DKQCMR025-Appendix 1 (Adapted for Kinetic Chromogenic BET)

1.0 Model and Sources

1.1 For the test method, the measured Endotoxin Concentration (C) is the primary output. The relative combined standard uncertainty uc(C) / C is the root-sum-square of the relative uncertainties of the available components:

uc(C) / C = √( (urep / C)2 + (ulin / C)2 + (ubias / C)2 )

2.0 CALCULATION INDIVIDUAL COMPONENT

2.1 Repeatability, urep

2.1.1 Result taken directly from the overall volumetric and pipetting uncertainty calculation for the BET method (incorporating sample dilution, standard serial dilution, and reagent dispense volumes as derived from the pipette calibration certificates).

2.1.2 Overall relative standard uncertainty for volumetric steps is 0.187%.

urep / C = 0.187% = 0.00187

2.2.3 Standard error of the regression (Sy,x) based on the reported equation y = 1.672x - 0.005.

2.2.3.1 Predicted value (ŷ)

a) x=0: 1.672(0) - 0.005 = -0.0050
b) x=0.0625: 1.672(0.0625) - 0.005 = 0.0995
c) x=0.125: 1.672(0.125) - 0.005 = 0.204
d) x=0.25: 1.672(0.25) - 0.005 = 0.413
e) x=0.5: 1.672(0.5) - 0.005 = 0.831
f) x=1.0: 1.672(1.0) - 0.005 = 1.667

2.2.3.2 Sum squared of actual with predicted value, Σ(y - ŷ)2.

a) (0.023 - (-0.005))2 = 0.000784
b) (0.101 - 0.0995)2 = 0.00000225
c) (0.199 - 0.204)2 = 0.000025
d) (0.415 - 0.413)2 = 0.000004
e) (0.839 - 0.831)2 = 0.000064
f) (1.654 - 1.667)2 = 0.000169
g) Sum of Squared Residuals (SSres) = 0.00104825

2.2.3.3 Standard error of the regression (Sy,x)

Sy,x = √( SSres / (n - 2) ) = √( 0.00104825 / (6 - 2) ) = √( 0.000262 ) = 0.01619

2.2.3.4 Uncertainty of the slope, uslope

a) Mean of x (x̄) = 1.9375 / 6 = 0.3229
b) Sxx = Σ(xi - x̄)2 = 0.7064
c) uslope = Sy,x / √Sxx = 0.01619 / √0.7064 = 0.01926

2.2.3.5 Relative Uncertainty of Linearity.

ulin / C = uslope / Slope = 0.01926 / 1.672 = 0.0115

2.3 Intercept bias, ubias

2.3.1 Result taken directly from Validation of the BET Standard Curve (assuming intercept acts as systemic bias).

2.3.2 Given y-intercept = -0.005, the intercept treats as systemic bias using rectangular distribution.

2.3.3 Calculation of ubias as below.

ubias = |-0.005| / √3 = 0.00289 OD units

2.3.4 Relative uncertainty for ubias using working concentration 0.5 EU/mL with mean OD = 0.838

ubias / C = 0.00289 / 0.838 = 0.0034

3.0 COMBINE AND EXPAND THE UNCERTAINTIES

3.1 Combination of relative uncertainty, uc(C) / C.

uc(C) / C = √( (0.00187)2 + (0.0115)2 + (0.0034)2 )

= √( 0.000003497 + 0.00013225 + 0.00001156 )

= √( 0.000147307 )

= 0.0121 (or 1.21%)

3.2 Expanded uncertainty, U.

U = k × uc

U = 2 × 0.0121 = 0.0242 (or 2.42%)
