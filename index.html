3. How Uncertainty Could Be Calculated if Additional Data Were Available

If the laboratory collects the missing data, the uncertainty can be estimated using a component-by-component approach consistent with the GUM and LAL-specific literature.

3.1 Calibration curve uncertainty

Obtain the raw reaction times for each standard replicate. Calculate the standard error of the regression, often denoted Sy.x. The standard uncertainty from the curve at a given concentration can then be estimated from the regression standard error and the number of data points.

3.2 Precision / repeatability

The CV% values in the report can be converted to a standard uncertainty for the tested concentration levels:

u = (CV% × Concentration) / 100

For example, using the reported CV values:

  • At 0.0100 EU/mL with CV = 1.92%: u = (1.92 × 0.0100) / 100 = 0.000192 EU/mL
  • At 0.0500 EU/mL with CV = 1.75%: u = (1.75 × 0.0500) / 100 = 0.000875 EU/mL

Limitation: These values only cover the concentration levels tested. For a full budget, precision should be assessed across the entire working range.

3.3 Pipetting and detector noise

Pipetting uncertainty can be estimated from pipette calibration data and volume precision. Detector noise can be estimated from repeated blank or standard readings. These components can then be combined with the calibration curve parameters to estimate the measurement relative standard deviation as a function of endotoxin concentration.

3.4 Combining the components

Individual standard uncertainties are combined to give the combined standard uncertainty:

uc = √(u12 + u22 + u32 + …)

The expanded uncertainty is obtained by multiplying the combined standard uncertainty by a coverage factor, typically k = 2 for approximately 95% confidence:

U = k × uc

4. Context from Scientific Literature

Published research on measurement uncertainty for chromogenic LAL assays has reported that final expanded measurement uncertainties can be substantial. One key study reported expanded uncertainties at 95% confidence ranging from approximately 90% to 127% of the bacterial endotoxin content for kinetic-chromogenic assays. A laboratory’s calculated uncertainty should be compared against such published ranges for reasonableness.

Important: The qualification PASS status in the lysate verification report confirms that the curve and precision met predefined acceptance criteria. It does not constitute a measurement uncertainty budget under ISO 17025.
