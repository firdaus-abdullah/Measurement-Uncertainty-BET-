Scope Limitation: This MU budget is strictly limited to the data generated by the Initial Qualification Test. It quantifies the uncertainty associated with interpolating a sample's reaction time against the qualified standard curve, as well as the system's within-run repeatability. It does not include product-specific recovery, dilution factors, or intermediate precision, which require separate validation studies.

1. Purpose and Scope

This report documents the measurement uncertainty (MU) budget for the standard curve and system repeatability, derived exclusively from the Initial Qualification Test (Lysate Verification) record. The measurand is the predicted endotoxin concentration \(C\) (in EU/mL) for a given onset time \(t\), based on the log-log linear regression model.

2. Method and Regression Parameters

The kinetic chromogenic method relates the onset time \(t\) to endotoxin concentration \(C\) through the empirical log–log relationship:

\[ \log_{10} t = a + b \cdot \log_{10} C \]

4. Step-by-Step Derivation

The following steps show exactly how the raw data from the qualification report produces the final uncertainty value.

Step 1: Log-Transformation of Raw Data

Because the model is a log-log regression, the concentrations (\(C\)) and reaction times (\(t\)) are converted to base-10 logarithms. The report provides 5 concentrations with 4 replicates each (\(N = 20\)).

Step 2: Calculate Regression Statistics

To calculate uncertainty, we need three statistical values derived from the table above:

  1. Mean of all \(x\) values (\(\bar{x}\)):
    \[ \bar{x} = \frac{4(-2) + 4(-1.301) + 4(-0.301) + 4(0.699) + 4(1.699)}{20} = \mathbf{-0.2408} \]
  2. Sum of Squares for \(x\) (\(S_{xx}\)):
    \[ S_{xx} = \sum (x_i - \bar{x})^2 = \mathbf{35.47} \]
  3. Residual Standard Deviation (\(s_{y/x}\)):
    This represents the average scatter of the points around the regression line. Using the reported equation \(\hat{y} = 3.075 - 0.226x\), the Sum of Squared Errors (\(SSE\)) is calculated as \(0.003146\).
    With \(N=20\) data points and 2 parameters (slope and intercept), degrees of freedom = \(N - 2 = 18\).
    \[ s_{y/x} = \sqrt{\frac{SSE}{18}} = \sqrt{\frac{0.003146}{18}} = \mathbf{0.01322} \]

Step 3: Calculate Standard Uncertainty of Interpolation (\(u_{cal}\))

We calculate the uncertainty for a sample tested in duplicate (\(m=2\)) near the mid-curve (\(C_0 = 0.500\) EU/mL).

\[ \begin{aligned} x_0 &= \log_{10}(0.500) = -0.30103 \\ u_{cal}(\log_{10}C_0) &= \frac{s_{y/x}}{|b|} \sqrt{\frac{1}{m} + \frac{1}{N} + \frac{(x_0 - \bar{x})^2}{S_{xx}}} \\ u_{cal} &= \frac{0.01322}{0.226} \sqrt{\frac{1}{2} + \frac{1}{20} + \frac{(-0.30103 - (-0.2408))^2}{35.47}} \\ u_{cal} &= 0.0585 \sqrt{0.500 + 0.050 + \frac{0.003627}{35.47}} \\ u_{cal} &= 0.0585 \sqrt{0.550 + 0.000102} \\ u_{cal} &= 0.0585 \times 0.7417 = \mathbf{0.04338} \end{aligned} \]

Note: This value (0.04338) is the standard uncertainty in \(\log_{10}\) units.

Step 4: Convert to Relative Uncertainty (\(u_{cal,rel}\))

Because we are interested in the uncertainty of the concentration (\(C\)), not the log of the concentration, we apply the conversion factor \(\ln(10) \approx 2.3026\):

\[ u_{cal,rel} = u_{cal} \times \ln(10) = 0.04338 \times 2.3026 = \mathbf{0.0999} \]

Converting to a percentage, we get 10.0%.

6. Uncertainty Statement (Qualification Only)

Based strictly on the Initial Qualification Test, for a sample interpolated near the mid-point of the standard curve (0.5 EU/mL) using duplicate wells, the relative combined standard uncertainty is:

\[ u_{c,\text{rel}}(C) = 10.0\% \]

The expanded relative uncertainty at approximately 95 % confidence is:

\[ U_{\text{rel}} = k \cdot u_{c,\text{rel}} = 2 \times 10.0\% = 20.0\% \]

Important: This statement represents only the calibration and system repeatability uncertainty derived from the qualification data. To report a full ISO 17025 MU for a customer sample, this value must be combined (via root-sum-square) with uncertainties for sample dilution, product-matrix recovery, and intermediate precision.
