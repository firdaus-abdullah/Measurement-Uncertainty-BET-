Measurement Uncertainty for Bacterial Endotoxin Test (Kinetic Chromogenic) – Micropipette Component

Note on values: As requested, the percentage signs (%) have been removed from the relative uncertainty values. For example, a value of 0.026 in this document represents 0.026%.

Conservative Approach: For volumes that fall between calibration points, the absolute standard uncertainty from the nearest maximum calibration point is used. This ensures the uncertainty is not underestimated.

1. Scope and Principle

This document provides only the micropipette component of the measurement uncertainty (MU) for the Kinetic Chromogenic BET. Other components—reader, incubation temperature, standard endotoxin, LAL reagent, analyst, plate, etc.—are added separately.

From each calibration certificate, the reported expanded uncertainty U is at approximately 95% confidence with coverage factor k = 2:

u(V) = U / 2
urel(V) = u(V) / V

For independent pipetting operations combined in a dilution or volume ratio:

urel,combined = √( Σi urel,i2 )

3. Worked Calculations for the BET Procedure

3.1 Dilution step: 183 µL sample into 3.5 mL LAL water

Dilution factor:

DF = (0.183 + 3.500) / 0.183 = 20.13

Uncertainties:

  • Vs = 183 µL by MM1 200 µL pipette: 0.0216
  • Vd = 3.5 mL = 3500 µL, prepared as 3 × 1000 µL + 500 µL using 1 mL pipettes:
u(Vd) = √( 3(0.305)2 + (0.205)2 ) = 0.567 µL
urel(Vd) = 0.567 / 3500 = 0.0162

Total volume Vtot = 3683 µL:

u(Vtot) = √(0.5672 + 0.03952) = 0.568 µL
urel(Vtot) = 0.568 / 3683 = 0.0154
urel(DF) = √(0.01542 + 0.02162) = 0.0265

3.2 Final well: 100 µL sample + 100 µL LAL reagent

R = Vs / (Vs + Vr)
  • Vs = 100 µL by MM1: 0.0325
  • Vr = 100 µL by MPM1 worst channel: 0.080
u(Vtot) = √(0.03252 + 0.0802) = 0.0864 µL
urel(Vtot) = 0.0864 / 200 = 0.0432
urel(R) = √(0.03252 + 0.04322) = 0.054

3.3 PPC spike: 10 µL of 5 EU/mL standard into 100 µL sample

CPPC = Cspike × Vsp / (Vs + Vsp)
  • Vsp = 10 µL by MM7: 0.085
  • Vs = 100 µL by MM1: 0.0325
u(Vtot) = √(0.00852 + 0.03252) = 0.0336 µL
urel(Vtot) = 0.0336 / 110 = 0.0305
urel(CPPC) = √(0.0852 + 0.03052) = 0.090

3.4 Standard endotoxin serial dilutions

For the serial dilution steps, we apply the conservative "Maximum Volume Rule" for all transfers using the 1 mL pipettes:

Step A: 0.1 mL + 0.9 mL dilution (Repeated 3 times)

  • 100 µL: Use 100 µL certificate point (\(u = 0.095\)) → urel = 0.095
  • 900 µL: Use 1000 µL certificate point conservatively (\(u = 0.305\)) → urel = 0.305 / 900 = 0.0339
urel,per dilution = √(0.0952 + 0.03392) = 0.101
urel,3 dil = √(3 × 0.1012) = 0.175

Step B: Final 0.2 mL + 0.8 mL dilution

  • 200 µL: Use 500 µL certificate point conservatively (\(u = 0.205\)) → urel = 0.205 / 200 = 0.1025
  • 800 µL: Use 1000 µL certificate point conservatively (\(u = 0.305\)) → urel = 0.305 / 800 = 0.0381
urel,final dilution = √(0.10252 + 0.03812) = 0.109

Total Standard Curve Pipetting Contribution:

urel,std curve = √(0.1752 + 0.1092) = 0.206

5. Final Summary of Combined Uncertainty

In measurement uncertainty, you only combine uncertainties that affect the calculation of a single reported result. Therefore, the Sample Result and the PPC Result are calculated separately. The PPC spike uncertainty is not added to the Sample uncertainty because the spike is not added to the sample wells.

6. Practical Recommendations

  1. 183 µL: use MM1 200 µL pipette; apply 200 µL certificate value conservatively.
  2. 900 µL and 800 µL: use 1 mL pipette (MM2/MM12/MM29); apply 1000 µL certificate value conservatively.
  3. 10 µL PPC spike: use MM7 20 µL pipette.
  4. 100 µL sample/standard wells: use MM1 200 µL pipette.
  5. 100 µL LAL reagent: use MPM1 8-channel pipette; use worst-channel uncertainty conservatively.
  6. Keep the Sample and PPC uncertainty calculations separate. Do not add the PPC spike uncertainty to the Sample uncertainty.
  7. Add separate MU components for reader, incubation temperature, standard endotoxin, LAL reagent, analyst, and assay repeatability.
