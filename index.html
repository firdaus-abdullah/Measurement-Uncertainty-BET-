Detailed Measurement Uncertainty Calculation (Multi-Analyst)

This document provides the step-by-step mathematical derivation for the uncertainty components using data from three analysts (Firdaus, Khairul, Shazwina).

1. Intermediate Precision (Reproducibility)

Based on the Standard Curve Slopes: -0.236, -0.229, -0.241

Mean (x̄) = (-0.236 + -0.229 + -0.241) / 3 = -0.23533 Deviations (x - x̄): (-0.236) - (-0.23533) = -0.00067 (-0.229) - (-0.23533) = 0.00633 (-0.241) - (-0.23533) = -0.00567 Squares (x - x̄)²: (-0.00067)² = 4.489e-7 ( 0.00633)² = 4.007e-5 (-0.00567)² = 3.215e-5 Sum of Squares = 7.267e-5 Variance (s²) = 7.267e-5 / (3-1) = 3.6335e-5 Standard Deviation (s) = √3.6335e-5 = 0.006028 Relative Uncertainty (u_int) = 0.006028 / 0.23533 = 0.0256 (2.56%)

2. Repeatability (Within-Run Precision)

Based on CV at 0.5 EU/mL: 2.56%, 0.70%, 1.07%

Mean CV = (2.56 + 0.70 + 1.07) / 3 = 1.4433% Relative Uncertainty (u_rep) = 1.44%

3. Calibration Curve Fit

Based on worst-case correlation coefficient (r = -0.996) and n = 5 points

Formula: √((1 - r²) / (n - 2)) r² = (-0.996)² = 0.992016 1 - r² = 0.007984 n - 2 = 3 0.007984 / 3 = 0.0026613 u_cal = √0.0026613 = 0.05159 (5.16%)

4. Bias (PPC Recovery)

Based on 9 recovery values: 130, 106, 117, 85, 102, 84, 90, 93, 100

Mean = 907 / 9 = 100.778% Sum of Squared Deviations = 1853.555 Variance (s²) = 1853.555 / 8 = 231.694 Standard Deviation (s) = 15.221% Standard Error (u_bias) = 15.221 / √9 = 5.07%

5. Temperature

Based on ±0.1°C variation and 10% per °C sensitivity assumption

u_temp = (0.1 / √3) * 10% = 0.58%
