Recommendation on Measurement Uncertainty for Kinetic Chromogenic Bacterial Endotoxin Test

Recommendation: No — a complete ISO 17025 measurement uncertainty for the Kinetic Chromogenic Bacterial Endotoxin Test cannot be calculated from the attached calibration certificates alone. The attached files mainly support the volumetric / dilution Type B uncertainty component of the BET method.

You can calculate a partial uncertainty budget for pipette delivery, dilution factors, standard endotoxin serial dilution, sample/PPC spike volumes, and LAL reagent dispense volume. However, you cannot calculate the full BET uncertainty without additional data for CSE assigned potency, LAL reagent variability, LAL reagent water, reader calibration, WinKQCL software, incubation control, plate homogeneity, analyst technique, sample matrix, PPC recovery, and replicate BET assay results.

SOP issues to resolve before issuing a defensible uncertainty budget: The SOP contains pipette/volume inconsistencies, for example “10 mL using 1 mL pipette”, “3.5 mL” without a stated pipette, and “10 µL using 1 mL pipette”. A 1 mL pipette is not suitable or calibrated for 10 µL.

1. What the certificates give you

For each pipette certificate, the reported Expanded Uncertainty, U, is at approximately k = 2:

u = U / 2 u_rel = u / V = U / (2V)

Use U/2, not U, as the standard uncertainty in the uncertainty budget.

Example from the MM1 200 µL certificate:

U_100µL = 0.065 µL u_100 = 0.065 / 2 = 0.0325 µL u_rel,100 = 0.0325 / 100 = 0.000325 = 0.0325%

3. Example calculation: sample dilution step 3.2

SOP step 3.2: dilute 183 µL into 3.5 mL LAL reagent water.

Assume final volume is additive:

V_s = 183 µL V_w = 3500 µL V_f = 3683 µL DF = V_s / V_f = 183 / 3683 = 0.04969

Volumetric uncertainty

For 183 µL using the MM1 200 µL pipette:

u_Vs = 0.0395 µL u_Vs / V_s = 0.0395 / 183 = 0.000216 = 0.0216%

For 3.5 mL prepared as 3 × 1000 µL + 1 × 500 µL using the MM2 1 mL pipette:

u_1000 = 0.305 µL u_500 = 0.205 µL u_Vw = sqrt(3 × (0.305)^2 + (0.205)^2) = 0.567 µL u_Vw / V_w = 0.567 / 3500 = 0.000162 = 0.0162%

For DF = V_s / V_f, the relative standard uncertainty is approximately:

u_DF / DF = sqrt( [ (V_w / V_f) × (u_Vs / V_s) ]^2 + [ u_Vw / V_f ]^2 ) = sqrt( [ (3500 / 3683) × 0.000216 ]^2 + [ 0.567 / 3683 ]^2 ) = sqrt( (0.000205)^2 + (0.000154)^2 ) = 0.000257 = 0.0257%

So the standard uncertainty contribution of this dilution is approximately:

u_rel,DF ≈ 0.026%

Expanded uncertainty at k = 2:

U_rel,DF ≈ 0.052%

This is only the volumetric/dilution component. It is not the BET method uncertainty.

4. Example calculation: standard endotoxin serial dilution

SOP steps 4.3.1.3–4.3.1.6:

  • 0.1 mL of 50 EU/mL into 0.9 mL water → 5 EU/mL
  • 0.1 mL of 5 EU/mL into 0.9 mL water → 0.5 EU/mL
  • 0.1 mL of 0.5 EU/mL into 0.9 mL water → 0.05 EU/mL
  • 0.2 mL of 0.05 EU/mL into 0.8 mL water → 0.01 EU/mL

For a 100 µL transfer using the MM2 1 mL pipette at 100 µL:

U = 0.17 µL u = 0.085 µL u / V = 0.085 / 100 = 0.00085 = 0.085%

For a 900 µL water volume, using 1000 µL U conservatively:

U = 0.61 µL u = 0.305 µL u / V = 0.305 / 900 = 0.000339 = 0.0339%

For each 0.1 mL into 0.9 mL dilution:

u_rel,DF = sqrt( (0.085%)^2 + (0.0339%)^2 ) = 0.0915%

Three similar 0.1 → 0.9 dilutions give:

u_rel,3 dilutions = sqrt( 3 × (0.0915%)^2 ) = 0.158%

For the 0.2 mL into 0.8 mL dilution, using MM1 200 µL at 200 µL:

u_rel,200 = 0.0395 / 200 = 0.0198%

For 800 µL using MM2 1 mL at 1000 µL U conservatively:

u_rel,800 = 0.305 / 800 = 0.0381%

u_rel,DF4 = sqrt( (0.0198%)^2 + (0.0381%)^2 ) = 0.0429%

Total pipetting contribution to standard concentration:

u_rel,std pipetting = sqrt( (0.158%)^2 + (0.0429%)^2 ) = 0.164%

This excludes CSE assigned potency uncertainty, reconstitution volume uncertainty, and LAL reagent variability. Therefore it is only a partial standard-concentration uncertainty.

5. Example calculation: PPC spike into a well

SOP 4.3.2.3: Add 10 µL of 5 EU/mL standard endotoxin to each PPC well containing 100 µL sample.

Final spike concentration in the well:

C_f = C_s × V_s / (V_m + V_s) C_f = 5 × 10 / (100 + 10) C_f = 0.4545 EU/mL

This is not 0.5 EU/mL. To obtain 0.5 EU/mL in 100 µL sample with a 10 µL spike, the spike concentration would need to be:

C_s = 0.5 × (110 / 10) = 5.5 EU/mL

or the spike volume would need to be about 11.1 µL if using 5 EU/mL. This SOP discrepancy should be resolved.

Uncertainty of the final spike concentration, using:

  • 10 µL MM7 at 50% point: u/V = 0.085%
  • 100 µL sample MM1 at 100 µL: u/V = 0.0325%
  • 5 EU/mL standard pipetting uncertainty from first dilution: 0.0915%

For C_f = C_s × V_s / (V_m + V_s):

u_Cf / C_f = sqrt( (u_Cs / C_s)^2 + [ (V_m / (V_m + V_s)) × (u_Vs / V_s) ]^2 + [ u_Vm / (V_m + V_s) ]^2 ) = sqrt( (0.0915%)^2 + [ (100 / 110) × 0.085% ]^2 + [ 0.0325 / 110 ]^2 ) = sqrt( (0.0915)^2 + (0.0773)^2 + (0.0295)^2 ) = 0.123%

So the partial volumetric standard uncertainty for the PPC well spike is about:

u_rel,PPC ≈ 0.12% U_rel,PPC ≈ 0.25% at k = 2

Again, this excludes CSE CoA uncertainty and LAL/reader/assay variability.

6. Example combined volumetric contribution

If you combine only the pipetting components for a sample result:

  • sample dilution 183 µL into 3.5 mL: 0.026%
  • 100 µL sample into well: 0.0325%
  • 100 µL LAL reagent by MPM1: ~0.080%
  • standard concentration pipetting: 0.164%

u_c,volumetric = sqrt( (0.026)^2 + (0.0325)^2 + (0.080)^2 + (0.164)^2 ) = 0.187%

Expanded volumetric-only:

U_volumetric = 2 × 0.187% = 0.374%

This does not represent the BET measurement uncertainty. Actual BET uncertainty is usually dominated by LAL reagent, standard curve, reader, incubation, and replicate assay variability, which are not in the attached certificates. Do not report 0.37% as the BET expanded uncertainty.

7. Recommended ISO 17025 approach

  1. Correct the SOP pipette assignments and volumes. Use a 20 µL pipette for 10 µL, not a 1 mL pipette. Define how 3.5 mL and 10 mL are measured. Clarify whether PPC is spiked in batch or in-well, and correct the 0.5 EU/mL calculation.
  2. Use the actual pipette ID and current certificate. Use U/2 as standard uncertainty. For volumes not calibrated, either calibrate at that volume or use the conservative nearest-higher volume with justification.
  3. Build a formal uncertainty budget for the BET result C in EU/mL. Include at least: CSE assigned concentration and reconstitution, serial dilution volumes, sample dilution volumes, sample and LAL dispense volumes, PPC spike volume, LAL reagent lot variability, reader/kinetic calibration, incubation temperature/time, standard curve regression, replicate well repeatability, analyst/intermediate precision, matrix effects, and PPC recovery.
  4. Use validation/replicate data for Type A. Estimate repeatability s_r and intermediate precision s_R from replicate BET assays at low/mid/high endotoxin levels. Combine with Type B components by quadrature:

    u_c = sqrt(u_A^2 + Σ u_B^2) U = k × u_c, with k = 2

  5. Report the uncertainty for the actual result. For example:

    C = 0.50 ± U EU/mL, k = 2

    State that U is the expanded uncertainty for the BET result, not just pipette volume.
Bottom line: The attached certificates are sufficient to calculate the pipette/dilution Type B contribution only. They are not sufficient to calculate the full ISO 17025 measurement uncertainty for the Kinetic Chromogenic BET. You can use the calculations above as the volumetric portion of the budget, but you must add CSE, LAL, reader, curve, incubation, analyst, and replicate-assay components before issuing a full BET uncertainty statement.
