Measurement Uncertainty for Bacterial Endotoxin Test (Kinetic Chromogenic) – Micropipette Component

1. Scope and Principle

This document provides only the micropipette component of the measurement uncertainty (MU) for the Kinetic Chromogenic BET. Other components—reader, incubation temperature, standard endotoxin, LAL reagent, analyst, plate, etc.—are to be added separately.

From each calibration certificate, the reported expanded uncertainty U is at approximately 95% confidence with coverage factor k = 2. Therefore:

u(V) = U / k = U / 2
urel(V) = u(V) / V

For independent pipetting operations combined in a dilution or volume ratio:

urel,combined = √( Σi urel,i2 )

Use relative standard uncertainties in the MU budget. Do not use the certificate U directly as a standard uncertainty.

3. Worked Calculations for the BET Procedure

3.1 Dilution step: 183 µL sample into 3.5 mL LAL water

Dilution factor:

DF = (Vs + Vd) / Vs = (0.183 + 3.500) / 0.183 = 20.13

Uncertainties:

  • Vs = 183 µL:
    u(Vs) = 0.0383 µL
    urel(Vs) = 0.0383 / 183 = 0.0209%
  • Vd = 3.5 mL = 3500 µL.
    If prepared as 3 × 1000 µL + 500 µL using 1 mL pipettes:
u(Vd) = √( 3(0.305)2 + (0.205)2 ) = 0.567 µL
urel(Vd) = 0.567 / 3500 = 0.0162%

Total volume Vtot = 3683 µL:

u(Vtot) = √(0.5672 + 0.03832) = 0.568 µL
urel(Vtot) = 0.568 / 3683 = 0.0154%

Therefore:

urel(DF) = √( (0.0154%)2 + (0.0209%)2 ) = 0.026%

Recommended MU input for this dilution:

urel,DF ≈ 0.026%

3.2 Final well: 100 µL sample + 100 µL LAL reagent

For the final well volume ratio:

R = Vs / (Vs + Vr)

where:

  • Vs = 100 µL delivered by MM1:
    u(Vs) = 0.0325 µL
    urel(Vs) = 0.0325%
  • Vr = 100 µL delivered by MPM1 8-channel, worst channel:
    u(Vr) = 0.080 µL
    urel(Vr) = 0.080%

Total volume Vtot = 200 µL:

u(Vtot) = √(0.03252 + 0.0802) = 0.0864 µL
urel(Vtot) = 0.0864 / 200 = 0.0432%

Thus:

urel(R) = √( (0.0325%)2 + (0.0432%)2 ) = 0.054%

Recommended MU input for final sample/reagent volume ratio:

urel,well ≈ 0.054%

If the same pipette and same volume are used for both standards and samples and the MU model assumes cancellation of systematic bias, this component may be reduced. For a conservative ISO 17025 budget, use the value above.

3.3 PPC spike: 10 µL of 5 EU/mL standard into 100 µL sample

PPC concentration before LAL reagent addition:

CPPC = Cspike × Vsp / (Vs + Vsp)

where:

  • Vsp = 10 µL by MM7:
    u(Vsp) = 0.0085 µL
    urel(Vsp) = 0.085%
  • Vs = 100 µL by MM1:
    u(Vs) = 0.0325 µL
    urel(Vs) = 0.0325%

Total Vtot = 110 µL:

u(Vtot) = √(0.00852 + 0.03252) = 0.0336 µL
urel(Vtot) = 0.0336 / 110 = 0.0305%

Therefore:

urel(CPPC) = √( (0.085%)2 + (0.0305%)2 ) = 0.090%

Recommended MU input for PPC spike:

urel,PPC ≈ 0.090%

Again, use the 20 µL pipette for the 10 µL spike. If a 1 mL pipette is used for 10 µL, the uncertainty will be much larger and not represented by the calibration certificate at 10 µL.

3.4 Standard endotoxin serial dilutions

For the serial dilution steps using 0.1 mL + 0.9 mL with 1 mL pipettes:

urel,100 = 0.095%
urel,900 = 0.0339%
urel,per dilution = √( (0.095%)2 + (0.0339%)2 ) = 0.100%

For three such dilutions:

urel,3 dil = √( 3 × (0.100%)2 ) = 0.173%

For the final 0.2 mL + 0.8 mL dilution:

urel,200 ≈ 0.0475%
urel,800 ≈ 0.0331%
urel,final dilution = √( (0.0475%)2 + (0.0331%)2 ) = 0.058%

Combined standard-curve pipetting contribution:

urel,std curve = √( (0.173%)2 + (0.058%)2 ) = 0.182%

So the micropipette contribution from standard-curve preparation is approximately:

urel,std curve ≈ 0.18%

If appropriate pipettes are used—e.g. 200 µL pipette for 100 µL and 1 mL pipette for 900 µL—this can be reduced to approximately 0.09%.

5. Combined Micropipette Contribution

For the sample result, if only the sample dilution and final well volume ratio are included:

urel,sample micropipette = √( (0.026%)2 + (0.054%)2 ) = 0.060%

Expanded for micropipette only:

Urel = k urel = 2(0.060%) = 0.12%

If standard-curve pipetting is also included as a micropipette component:

urel,total micropipette = √( (0.060%)2 + (0.182%)2 ) = 0.192%
Urel = 2(0.192%) = 0.38%

For PPC:

urel,PPC = 0.090%
Urel,PPC = 0.18%

These are small compared with typical BET assay variability. The final combined MU should be dominated by LAL assay repeatability, standard curve fit, incubation/reader performance, and analyst technique.

6. Practical Recommendations

  1. Use MM7 20 µL for the 10 µL PPC spike, not a 1 mL pipette.
  2. Use MM1 200 µL for 100 µL sample/standard wells and for 183 µL dilution, not a 1 mL pipette.
  3. Use MPM1 8-channel only at 100 µL for reagent addition; use the worst-channel uncertainty for conservative MU.
  4. For volumes between calibration points, use linear interpolation between adjacent certificate volumes or the largest urel among bracketing volumes.
  5. Report micropipette uncertainty as relative standard uncertainty and combine in quadrature.
  6. Add separate components for:
    • pipetting repeatability by analyst, if not covered by calibration;
    • temperature/viscosity/tip effects;
    • reader/instrument;
    • standard endotoxin purity and reconstitution;
    • LAL reagent variability;
    • assay repeatability.

Recommended conservative micropipette inputs for the BET MU budget:

  • Dilution factor: urel = 0.026%
  • Final sample/reagent ratio: urel = 0.054%
  • PPC concentration: urel = 0.090%
  • Standard curve pipetting: urel ≈ 0.18% if using 1 mL pipettes; lower if correct-volume pipettes are used.
